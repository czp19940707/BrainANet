# BrainANet: an Anatomical Brain Representation Network with Large-scale Self-supervised Learning for Brain Disease Diagnosis
This repository provides the official implementation of BrainANet, a framework for constructing individualized anatomical brain networks from T1-weighted MRI. Specifically, it learns adaptive regional representations using a self-supervised patch-level Swin Transformer trained on large-scale T1-weighted MRI data, and models interregional anatomical similarity through pairwise cosine similarity.

# Supplementary Material 
The SupplementaryMaterials.pdf is the supplementary material for the paper "BrainANet: an Anatomical Brain Representation Network with Large-scale Self-supervised Learning for Brain Disease Diagnosis" published in the IEEE Journal of Biomedical and Health Informatics.
